# StudyQuest Visual Direction — v5

The reference image in this folder is a visual direction board for the responsive redesign.

## Themes
- **Ice** — default natural theme for the desktop experience: frosted glass, cyan/blue glow, violet accents, fantasy atmosphere.
- **Dark** — minimal dark theme with restrained neon accents.
- **Light** — clean white theme for bright environments.

## Responsive intent
- Desktop: persistent left navigation + wide content canvas + premium visual panels.
- Mobile/tablet: compact top navigation and existing bottom navigation remain the primary navigation pattern.
- The Premium page is a visual/product shell. Subscription billing itself is intentionally not faked; it can be connected later to a real payment provider and server-side entitlement system.
